# 開発ユニット分割

## 概要

本ドキュメントは、[user_stories.md](user_stories.md) と [system_architecture.md](system_architecture.md) を入力として、開発ユニットの分割と各ユニットの責務を定義する。

## ユニット一覧

| ユニット | 種別 |
|---------|------|
| フロントエンド | フロントエンド |
| メイン API | バックエンド (SAM) |
| 解析 API | バックエンド (SAM) |
| インフラ | インフラ (CDK) |
| CI/CD | CI/CD (CloudFormation) |

---

## フロントエンド

### 責務

- UI の構築とユーザー操作の処理
- メイン API・解析 API への REST API 呼び出し
- Cognito Managed Login との連携（ログイン・ログアウト・コールバック）
- 将棋盤コンポーネント（shogi-board ライブラリ）の提供

### 対応するユーザーストーリー

| ストーリー | 内容 | API 呼び出し先 |
|-----------|------|---------------|
| US-1.1〜1.4 | 認証（アカウント作成・ログイン・ログアウト・パスワード変更） | Cognito（直接） |
| US-2.1 | ダッシュボード表示 | メイン API |
| US-3.1〜3.8 | 棋譜管理（一覧・作成・詳細・編集・削除・エクスプローラー） | メイン API |
| US-4.1〜4.2 | 棋譜共有（設定・閲覧） | メイン API |
| US-5.1〜5.5 | タグ管理（一覧・作成・詳細・編集・削除） | メイン API |
| US-6.1 | AI 局面解析の実行・結果表示 | 解析 API |
| US-7.1〜7.2 | ユーザー管理（プロフィール・アカウント削除） | メイン API |
| US-8.1〜8.2 | ナビゲーション | - |

---

## メイン API

### 責務

- ユーザー管理（プロフィール取得・アカウント削除）
- 棋譜の CRUD（作成・取得・更新・削除・一覧・エクスプローラー）
- タグの CRUD（作成・取得・更新・削除・一覧）
- 棋譜共有（共有棋譜の公開取得）
- 棋譜とタグの関連管理

### 管理するリソース

- API Gateway + Lambda
- データストア（棋譜・タグ・ユーザーデータ）

### 対応するユーザーストーリー

| ストーリー | 提供する機能 |
|-----------|------------|
| US-3.1 | 棋譜一覧の取得 |
| US-3.2 | 棋譜の作成 |
| US-3.5 | 棋譜詳細の取得 |
| US-3.6 | 棋譜の更新 |
| US-3.7 | 棋譜の削除 |
| US-3.8 | フォルダ階層での棋譜取得 |
| US-4.1 | 棋譜の共有設定（作成・更新時） |
| US-4.2 | 共有棋譜の取得（認証不要） |
| US-5.1 | タグ一覧の取得 |
| US-5.2 | タグの作成 |
| US-5.3 | タグ別棋譜一覧の取得 |
| US-5.4 | タグの更新 |
| US-5.5 | タグの削除 |
| US-7.1 | ユーザー情報の取得 |
| US-7.2 | アカウントの削除 |

## 解析 API

### 責務

- 局面解析リクエストの受付（DynamoDB にレコードを作成し、解析を開始する）
- 将棋エンジンによる解析の実行（または実行の委譲）
- 解析完了時に DynamoDB のレコードを結果で更新する
- フロントエンドからの解析状況問い合わせに対し、現在のステータスと結果を返却する

### 管理するリソース

- API Gateway + Lambda
- DynamoDB（解析結果の保持）
- その他解析に必要なリソース（キュー等）

### 対応するユーザーストーリー

| ストーリー | 提供する機能 |
|-----------|------------|
| US-6.1 | 解析リクエストの受付、解析結果の返却 |

### メイン API との独立性

- 解析 API はメイン API のリソースを参照しない
- フロントエンドが解析を実行したい場合は解析 API に直接アクセスする
- 解析に必要なユーザー情報は Cognito の Access Token から取得する（メイン API への問い合わせは不要）

---

## インフラ

### 責務

- Cognito User Pool の作成・管理（共通リソーススタック）
- S3 バケットの作成（フロントエンド配信用）
- CloudFront ディストリビューションの作成（配信基盤スタック）
  - S3 をデフォルトオリジンに設定
  - メイン API・解析 API の API Gateway をオリジンとして登録し、パスパターンで振り分け

### 対応するユーザーストーリー

直接的なユーザーストーリーへの対応はないが、全ユニットの動作基盤を提供する。

---

## CI/CD

### 責務

- フロントエンド・メイン API・解析 API・インフラそれぞれの CodeBuild プロジェクトを CloudFormation で作成
- GitHub リポジトリとの連携

### 対応するユーザーストーリー

直接的なユーザーストーリーへの対応はないが、全ユニットのデプロイを自動化する。
