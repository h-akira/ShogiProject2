# API エンドポイント一覧（暫定）

> 本ドキュメントは暫定版である。OpenAPI 定義で置き換える予定。

## メイン API

ベースパス: `/api/v1/main`

### ユーザー

| メソッド | パス | 認証 | 概要 |
|---------|------|------|------|
| GET | `/users/me` | 要 | ログインユーザーの情報取得 |
| DELETE | `/users/me` | 要 | アカウント削除 |

### 棋譜

| メソッド | パス | 認証 | 概要 |
|---------|------|------|------|
| GET | `/kifus/recent` | 要 | 最近の棋譜一覧の取得 |
| POST | `/kifus` | 要 | 棋譜の作成 |
| GET | `/kifus/explorer` | 要 | フォルダ階層での棋譜取得 |
| GET | `/kifus/{kid}` | 要 | 棋譜詳細の取得 |
| PUT | `/kifus/{kid}` | 要 | 棋譜の更新 |
| DELETE | `/kifus/{kid}` | 要 | 棋譜の削除 |
| PUT | `/kifus/{kid}/share-code` | 要 | 共有コードの再生成 |

### 共有棋譜

| メソッド | パス | 認証 | 概要 |
|---------|------|------|------|
| GET | `/shared/{share_code}` | 不要 | 共有棋譜の取得 |

### タグ

| メソッド | パス | 認証 | 概要 |
|---------|------|------|------|
| GET | `/tags` | 要 | タグ一覧の取得 |
| POST | `/tags` | 要 | タグの作成 |
| GET | `/tags/{tid}` | 要 | タグ詳細の取得（関連棋譜含む） |
| PUT | `/tags/{tid}` | 要 | タグの更新 |
| DELETE | `/tags/{tid}` | 要 | タグの削除 |

---

## 解析 API

ベースパス: `/api/v1/analysis`

| メソッド | パス | 認証 | 概要 |
|---------|------|------|------|
| POST | `/requests` | 要 | 解析リクエストの作成 |
| GET | `/requests/{aid}` | 要 | 解析ステータス・結果の取得 |
