# ユーザーストーリー

## 概要

本ドキュメントは、将棋棋譜管理アプリケーション「ShogiProject」のユーザーストーリーをまとめたものである。
フロントエンドの実装を基に、ユーザーが本アプリケーションで実現できることを網羅的に記述する。

## アクター定義

| アクター | 説明 |
|---------|------|
| 未ログインユーザー | アカウント未作成、またはログインしていない状態のユーザー |
| ログインユーザー | Cognito 認証を経てログイン済みのユーザー |

---

## 1. 認証

### US-1.1: アカウント作成

- **アクター**: 未ログインユーザー
- **ストーリー**: ユーザーとして、アカウントを作成したい。自分の棋譜を安全に保管・管理できるようにするためである。
- **受け入れ条件**:
  - ホームページの「今すぐ始める」または「ログイン」ボタンからサインアップ画面に遷移できる
  - メールアドレス・パスワードを入力してアカウントを作成できる
  - アカウント作成後、コールバック処理を経てアプリケーションにリダイレクトされる

### US-1.2: ログイン

- **アクター**: 未ログインユーザー
- **ストーリー**: ユーザーとして、自分のアカウントにログインしたい。保存済みの棋譜やタグにアクセスするためである。
- **受け入れ条件**:
  - ホームページまたはヘッダーの「ログイン」ボタンからログイン画面に遷移できる
  - 認証成功後、コールバック処理を経てダッシュボード（ホームページのログイン済み状態）が表示される
  - ヘッダーにユーザー名が表示され、ナビゲーションメニュー（マイページ・エクスプローラー・タグ一覧）が利用可能になる

### US-1.3: ログアウト

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、ログアウトしたい。セッションを終了し、セキュリティを確保するためである。
- **受け入れ条件**:
  - ヘッダーの「ログアウト」ボタンをクリックするとログアウト処理が実行される
  - ログアウト後、ホームページ（未ログイン状態）にリダイレクトされる

### US-1.4: パスワード変更

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、パスワードを変更したい。アカウントのセキュリティを維持するためである。
- **受け入れ条件**:
  - プロフィールページの「パスワード変更」ボタンからパスワード変更画面に遷移できる

## 2. ダッシュボード

### US-2.1: ダッシュボードの表示

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、ログイン後にダッシュボードを確認したい。主要機能にすばやくアクセスするためである。
- **受け入れ条件**:
  - ホームページにダッシュボードとして以下の 4 つのカードが表示される
    - マイページ: 最近の棋譜を確認・管理
    - エクスプローラー: フォルダ階層で棋譜を閲覧
    - タグ一覧: タグで棋譜を分類・検索
    - 棋譜作成: 新しい棋譜を登録
  - 各カードをクリックすると対応するページに遷移する

---

## 3. 棋譜管理

### US-3.1: 棋譜一覧の表示（マイページ）

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、保存した棋譜の一覧を確認したい。棋譜を管理・閲覧するためである。
- **受け入れ条件**:
  - マイページに保存棋譜数のサマリーが表示される
  - 最近更新された棋譜が最大 10 件、テーブル形式で表示される
  - テーブルにはスラグ、先後、勝敗、タグ、更新日時が含まれる
  - 棋譜が 0 件の場合は「棋譜がありません」と表示される
  - 行をクリックすると棋譜詳細ページに遷移する

### US-3.2: 棋譜の作成

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、新しい棋譜を登録したい。対局記録を保存・管理するためである。
- **受け入れ条件**:
  - 以下の項目を入力して棋譜を作成できる
    - スラグ（識別名。`/` 区切りで階層化可能。`.kif` は自動付与）
    - 「自動生成」ボタンをクリックすると `000_未分類/YYYY/MMDD/HHmmss` 形式のスラグが現在日時で生成・入力される
    - 先後（なし / 先手 / 後手）
    - 勝敗（なし / 勝ち / 負け / 千日手 / 持将棋）
    - タグ（既存タグから複数選択）
    - メモ（自由入力テキスト）
    - 共有（有効 / 無効）
    - 棋譜データ（将棋盤 GUI 入力、または KIF テキスト直接入力）
  - 保存に成功すると作成された棋譜の詳細ページに遷移する

### US-3.3: 棋譜の将棋盤 GUI 入力

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、将棋盤の GUI で駒を動かして棋譜を入力したい。直感的に対局を再現するためである。
- **受け入れ条件**:
  - 棋譜作成・編集ページで「将棋盤」入力モードを選択できる
  - 将棋盤コンポーネントが input モードで表示される
  - 盤上のマスをクリックして駒を選択し、移動先をクリックして駒を動かせる
  - 持ち駒を選択して盤上に打てる
  - 成・不成の選択ができる
  - 「一手戻す」操作で直前の入力を取り消せる
  - 「初期局面に戻る」操作で盤面をリセットできる（新規作成時）

### US-3.4: 棋譜の KIF テキスト入力

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、KIF 形式のテキストを貼り付けて棋譜を入力したい。外部ソースからの棋譜を効率的に取り込むためである。
- **受け入れ条件**:
  - 棋譜作成・編集ページで「テキスト」入力モードを選択できる
  - KIF 形式のテキストを入力できるテキストエリアが表示される
  - KIF 形式の棋譜テキストを貼り付けて保存できる

### US-3.5: 棋譜の詳細表示・再生

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、保存した棋譜を詳細表示し再生したい。対局の流れを確認・研究するためである。
- **受け入れ条件**:
  - 棋譜詳細ページに以下が表示される
    - 将棋盤（playback モード）: 棋譜の再生、コマ送り・巻き戻しが可能
    - メタ情報: 先後、勝敗、作成日、更新日
    - タグ: 付与されたタグが Chip として表示される（クリックでタグ詳細に遷移）
    - メモ: 登録されたメモが表示される
  - 棋譜の再生コントロール（再生・停止・コマ送り・コマ戻し・先頭・末尾）が利用できる
  - 棋譜テキスト（KIF形式）が表示される
  - コピーボタン（クリップボードアイコン付き）をクリックすると、KIF形式の棋譜テキストがクリップボードにコピーされる

### US-3.6: 棋譜の編集

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、保存済みの棋譜を編集したい。情報の修正や追記を行うためである。
- **受け入れ条件**:
  - 棋譜詳細ページの「編集」ボタンから編集ページに遷移できる
  - 既存のデータ（スラグ、先後、勝敗、タグ、メモ、共有、棋譜データ）がフォームにプリロードされる
  - 将棋盤入力モードでも既存の棋譜データ（指し手）が盤面にプリロードされ、最終局面が表示される
  - 各項目を変更して「更新」ボタンで保存できる
  - 「変更を破棄」操作で保存済みの棋譜データを復元できる
  - 更新成功後、棋譜詳細ページに遷移する

### US-3.7: 棋譜の削除

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、不要な棋譜を削除したい。データを整理するためである。
- **受け入れ条件**:
  - 棋譜詳細ページの「削除」ボタンをクリックすると確認ダイアログが表示される
  - 確認ダイアログに「この棋譜を削除しますか？この操作は取り消せません。」と表示される
  - 「削除」を選択すると棋譜が削除され、マイページに遷移する
  - 「キャンセル」を選択すると削除は実行されない

### US-3.8: 棋譜のフォルダ階層管理

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、棋譜をフォルダ階層で整理して閲覧したい。大量の棋譜を効率的に管理するためである。
- **受け入れ条件**:
  - エクスプローラーページでフォルダ階層が表示される
  - パンくずリストで現在の階層が示され、各階層をクリックして移動できる
  - フォルダカードにフォルダ名と件数が表示され、クリックでそのフォルダに移動できる
  - 棋譜ファイルをクリックすると棋譜詳細ページに遷移する
  - フォルダ・ファイルが存在しない場合は「このフォルダは空です」と表示される
  - ブラウザの戻る・進むボタンで階層間を移動できる

## 4. 棋譜共有

### US-4.1: 棋譜の共有設定

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、棋譜の共有を有効にしたい。他のユーザーにログイン不要で棋譜を見せるためである。
- **受け入れ条件**:
  - 棋譜の作成・編集時に共有のオン/オフを切り替えられる
  - 共有コードはサーバー側で自動生成され、棋譜作成時に自動的に付与される
  - 共有が有効な棋譜の詳細ページに共有コード（URL）が表示される
  - 共有リンクのコピーボタンでクリップボードに URL をコピーできる
  - 「共有コードを再生成」ボタンがあり、クリックすると確認ダイアログが表示される
  - 確認ダイアログに「既存の共有リンクが無効になります。再生成しますか？」と表示される
  - 再生成後、新しい共有リンクが表示される

### US-4.2: 共有棋譜の閲覧

- **アクター**: 未ログインユーザー
- **ストーリー**: ユーザーとして、共有リンクから棋譜を閲覧したい。ログインせずに他者の棋譜を確認するためである。
- **受け入れ条件**:
  - 共有リンク (`/shared/:share_code`) にアクセスすると、ログイン不要で棋譜を閲覧できる
  - 将棋盤が playback モードで表示され、棋譜を再生できる
  - メタ情報（先後、勝敗、作成日、更新日）とメモが表示される
  - 棋譜テキスト（KIF形式）が表示される
  - コピーボタン（クリップボードアイコン付き）をクリックすると、KIF形式の棋譜テキストがクリップボードにコピーされる
  - 編集・削除・AI 解析・タグなどの機能は利用できない（読み取り専用）
  - 無効な共有コードの場合は「共有棋譜が見つかりません」と表示される

## 5. タグ管理

### US-5.1: タグ一覧の表示

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、作成したタグの一覧を確認したい。タグを管理するためである。
- **受け入れ条件**:
  - タグ一覧ページにテーブル形式でタグが表示される
  - テーブルにはタグ名、作成日、更新日、操作（編集・削除）が含まれる
  - タグが 0 件の場合は「タグがありません」と表示される
  - 行をクリックするとタグ詳細ページに遷移する

### US-5.2: タグの作成

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、新しいタグを作成したい。棋譜を分類・整理するためである。
- **受け入れ条件**:
  - タグ名（1〜127 文字）を入力して保存できる
  - タグ名が空の場合は保存ボタンが無効になる
  - 作成成功後、タグ一覧ページに遷移する

### US-5.3: タグ別棋譜の表示

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、特定のタグが付与された棋譜を一覧で確認したい。タグによる棋譜の検索・絞り込みを行うためである。
- **受け入れ条件**:
  - タグ詳細ページにタグ名と関連棋譜数が表示される
  - そのタグが付与された棋譜がテーブル形式で表示される（スラグ、作成日、更新日）
  - 棋譜が 0 件の場合は「このタグが付与された棋譜はありません」と表示される
  - 棋譜の行をクリックすると棋譜詳細ページに遷移する

### US-5.4: タグの編集

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、タグ名を変更したい。分類体系を改善するためである。
- **受け入れ条件**:
  - タグ一覧またはタグ詳細の「編集」ボタンからタグ編集ページに遷移できる
  - 既存のタグ名がフォームにプリロードされる
  - タグ名を変更して「更新」ボタンで保存できる
  - 更新成功後、タグ一覧ページに遷移する

### US-5.5: タグの削除

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、不要なタグを削除したい。分類体系を整理するためである。
- **受け入れ条件**:
  - タグ一覧またはタグ詳細の「削除」ボタンで確認ダイアログが表示される
  - 確認ダイアログに「タグ「{名前}」を削除しますか？棋譜に付与されている関連データも同時に削除されます。」と表示される
  - 「削除」を選択するとタグが削除される
  - タグ一覧からの削除時はリストから即座に除去される
  - タグ詳細からの削除時はタグ一覧ページに遷移する

## 6. AI 局面解析

### US-6.1: AI 局面解析の実行

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、棋譜の任意の局面を AI に解析させたい。最善手や形勢判断を知り、棋力向上に役立てるためである。
- **受け入れ条件**:
  - 棋譜詳細ページで将棋盤を任意の局面まで再生した状態で解析を実行できる
  - 思考時間を 3 秒 / 5 秒 / 10 秒から選択できる
  - 「解析」ボタンをクリックすると解析リクエストが送信される
  - 解析中はスピナーと「解析中...」が表示される
  - 解析完了時、候補手のリスト（順位、スコア、読み筋）が表示される
  - 解析失敗時はエラーメッセージが表示される

## 7. ユーザー管理

### US-7.1: プロフィールの確認

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、自分のプロフィール情報を確認したい。アカウント情報を把握するためである。
- **受け入れ条件**:
  - プロフィールページに以下が表示される
    - ユーザー名
    - メールアドレス（認証済みの場合はチェックマーク付き）
    - 登録日
  - ヘッダーのユーザー名ボタンからプロフィールページに遷移できる

### US-7.2: アカウントの削除

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、アカウントを削除したい。サービスの利用をやめるためである。
- **受け入れ条件**:
  - プロフィールページの「アカウント削除」ボタンからアカウント削除ページに遷移できる
  - 警告メッセージ「アカウントを削除すると、すべての棋譜・タグデータが削除されます。この操作は取り消せません。」が表示される
  - パスワードを入力して「アカウントを削除」ボタンをクリックできる（パスワード未入力時はボタンが無効）
  - 最終確認ダイアログ「本当にアカウントを削除しますか？すべてのデータが失われます。」が表示される
  - 「削除する」を選択するとアカウントが削除され、ログアウト後にホームページに遷移する

## 8. ナビゲーション

### US-8.1: ヘッダーナビゲーション

- **アクター**: ログインユーザー
- **ストーリー**: ユーザーとして、ヘッダーから主要ページに移動したい。アプリケーション内を効率的に移動するためである。
- **受け入れ条件**:
  - ヘッダーに以下のナビゲーションが表示される
    - アプリロゴ「将棋棋譜管理」（クリックでホームに遷移）
    - マイページ
    - エクスプローラー
    - タグ一覧
    - ユーザー名ボタン（クリックでプロフィールページに遷移）
    - ログアウトボタン

### US-8.2: 未ログイン時のランディングページ

- **アクター**: 未ログインユーザー
- **ストーリー**: ユーザーとして、アプリケーションの概要を把握したい。サービスの内容を理解してから利用を開始するためである。
- **受け入れ条件**:
  - ホームページにヒーローセクションが表示される
    - タイトル「将棋棋譜管理」
    - 説明文「あなたの棋譜を安全に保管・整理し、AI局面解析で棋力向上を支援します。」
  - 「ログイン」「今すぐ始める」ボタンが表示される
  - ヘッダーにはアプリロゴと「ログイン」ボタンのみが表示される（ナビゲーションメニューは非表示）
