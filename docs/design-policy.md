# デザイン方針

将棋盤の木色（`#dcb35c`）と調和する、温かみのあるライトテーマを基本とする。

---

## 全体方針

- 落ち着いた和のトーンを意識しつつ、モダンなUIを目指す
- 派手な装飾は避け、コンテンツ（将棋盤・棋譜データ）を主役にする
- ダークモードは使用しない（ライトテーマ固定）

---

## レイアウト

- **ナビゲーションバー**: ページ上部に固定配置（PrimeVue Menubar）
  - 左: アプリ名「将棋棋譜管理」
  - 中央: 主要ナビゲーション（棋譜一覧、エクスプローラー、タグ一覧）
  - 右: ユーザーメニュー（プロフィール、ログアウト）/ ログインボタン
- **メインコンテンツ**: 最大幅 1200px、中央揃え
- **フッター**: シンプルなコピーライト表示

---

## カラーパレット

```
背景（ページ全体）   #faf6f0   温かみのあるオフホワイト
カード/パネル背景     #fff      白
テキスト（メイン）    #2c2c2c   ソフトな黒
テキスト（補助）      #5a5a5a   ミディアムグレー
ボーダー              #d4c5a9   薄い木色系
アクセント            #8b4513   SaddleBrown（将棋盤の枠色）
アクセント（明）      #c08040   ライトブラウン（ホバー等）
リンク/プライマリ     #2a6496   落ち着いた青
エラー/赤             #b91c1c
成功/緑               #166534
```

### 将棋盤との調和

- 盤面色 `#dcb35c` を基準に、ページ背景は盤面より明るく彩度を落とす
- UI要素のボーダーに木色系 `#d4c5a9` を使い、盤面と地続きの印象にする
- アクセントカラーは盤面の枠色 `#8b4513` を流用する

## タイポグラフィ

- **本文フォント**: system-ui, 'Hiragino Sans', 'Hiragino Kaku Gothic ProN', 'Noto Sans JP', sans-serif
- **サイズ**: base 1rem / 補助 0.875rem / 小 0.75rem

---

## コンポーネント指針

### PrimeVue テーマ

- Aura プリセットを使用
- **ダークモード無効**（`darkModeSelector: false`）

### ボタン

- 白背景 + 木色系ボーダー（`#d4c5a9`）
- ホバー時は薄い木色背景（`#f5efe5`）
- テキスト色は `#2c2c2c` を明示

### バッジ・ラベル

- テキストと背景のコントラスト比 **4.5:1 以上**を確保する
- 薄い背景色を使う場合はテキスト色を十分に濃くする
