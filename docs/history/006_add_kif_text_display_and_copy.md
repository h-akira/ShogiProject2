# user_stories.md 変更通知: 棋譜テキスト表示・クリップボードコピー機能の追加

## 変更概要

`docs/user_stories.md` の US-3.5（棋譜の詳細表示・再生）と US-4.2（共有棋譜の閲覧）に、棋譜テキスト（KIF形式）の表示およびクリップボードコピー機能の受け入れ条件を追加した。

## 変更理由

- 棋譜再生ページに将棋盤はあるが、棋譜テキスト（手順リスト）が表示されていなかった
- 他の将棋アプリとの連携のため、KIF形式の棋譜テキストをクリップボードにコピーする機能が求められた

## 変更内容

### US-3.5: 棋譜の詳細表示・再生

以下の受け入れ条件を追加:

- 棋譜テキスト（KIF形式）が表示される
- コピーボタン（クリップボードアイコン付き）をクリックすると、KIF形式の棋譜テキストがクリップボードにコピーされる

### US-4.2: 共有棋譜の閲覧

以下の受け入れ条件を追加:

- 棋譜テキスト（KIF形式）が表示される
- コピーボタン（クリップボードアイコン付き）をクリックすると、KIF形式の棋譜テキストがクリップボードにコピーされる

## 影響を受けるユニット

| ユニット | 影響 |
|---------|------|
| フロントエンド | `KifuDetailPage.vue`, `SharedKifuPage.vue` に棋譜テキスト表示・コピーボタンを追加 |
| メイン API | なし（`kif` フィールドは既にレスポンスに含まれている） |
| 解析 API | なし |
| インフラ | なし |
