# openapi_main.yaml 変更通知: 409 レスポンス追加

## 変更概要

`docs/openapi_main.yaml` に 4 エンドポイントの 409 (Conflict) レスポンスを追加した。slug またはタグ名がユーザー内で重複した場合に返却される。

## 対象エンドポイント

| エンドポイント | 409 の条件 |
|--------------|-----------|
| `POST /kifus` (createKifu) | 同一ユーザー内に同じ slug が既に存在する |
| `PUT /kifus/{kid}` (updateKifu) | slug 変更時に同一ユーザー内に同じ slug が既に存在する |
| `POST /tags` (createTag) | 同一ユーザー内に同じタグ名が既に存在する |
| `PUT /tags/{tid}` (updateTag) | タグ名変更時に同一ユーザー内に同じタグ名が既に存在する |

## レスポンス形式

既存の Error スキーマと同一。

```json
{
  "message": "エラーメッセージ"
}
```

## フロントエンド側の対応

1. `orval.config.ts` で再生成を実行する（`npx orval`）
2. 棋譜作成・更新、タグ作成・更新の各画面で 409 エラー時のユーザー向けメッセージ表示を追加する
   - 棋譜: 「同じ名前の棋譜が既に存在します」等
   - タグ: 「同じ名前のタグが既に存在します」等
